# Security policy

## Supported versions

Security fixes are applied to the default branch. Published package versions are immutable; use the latest release when possible.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use a private GitHub Security Advisory for this repository when enabled. If private reporting is unavailable, contact the repository maintainers through the private contact mechanism configured in the repository settings and include reproduction steps, affected project/version, impact, and a suggested mitigation.

Do not include credentials, private keys, or personal data in a report.
