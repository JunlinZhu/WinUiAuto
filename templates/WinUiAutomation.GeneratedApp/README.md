# WinUiAutomation.GeneratedApp

Standalone console template for running C# generated by `WinUiAutomation.Studio`.

## Use

1. Build the native x64 library from the repository root:

   ```powershell
   msbuild .\UiAutoLib\UiAutoLib.vcxproj /t:Build /p:Configuration=Release /p:Platform=x64 /p:PlatformToolset=v143
   ```

2. Open `Program.cs`.
3. In Studio, record the workflow and click **Generate Code**.
4. Paste the generated `WinUiAutomation_yyyyMMddHHmm()` method into the `Program` class, replacing `RunGeneratedAutomation`.
5. Change `Main` to call the generated method name, for example:

   ```csharp
   private static void Main()
   {
	   WinUiAutomation_202611181307();
   }
   ```

6. Build and run from this directory:

   ```powershell
   dotnet run --project .\WinUiAutomation.GeneratedApp.csproj -c Release
   ```

The project builds the repository's `UiAutoLib` project, then copies `UiAutoLib.dll` from `x64\$(Configuration)` into the app output. Run it from an interactive, unlocked Windows desktop session. Generated code performs real input; review it before running.
